This project is implemented as part of Week-6 Assignment for the GUVI – Chubb .NET Track.
It demonstrates building a .NET 8 Minimal API with:
- EF Core InMemory Database
- Repository Layer
- Service Layer
- CRUD Endpoints
- Unit Tests (xUnit + Moq)
- Integration Tests (WebApplicationFactory)
- Clean Architecture Folder Structure
